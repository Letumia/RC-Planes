# RC-Planes
A repo of RC planes i designed with openVSP on my spare time.

# Teenage Disaster 150/ [TD150]
This plane was based off a cessna plane and is easy enough to develop in a workshop. Item list bellow:

*x1 Brushless Motor*

*x2 Servos*

*x1 ESC* 

*x1 3S LiPo Battery*

*x1 Propeller of choice*

*x1 RC Controller and receiver*
